Тема: "3DOF платформа для симрейсинга на 4х опорах" 
Цель: Создать рабочий прототип одной (если получится всех 4х) опоры, которая будет управляться с помощью приложения на ПК, передающего данные о необходимом угле наклона и высоте платформы. В основе будет шаговый двигатель небольшой мощности и контроллер (модель контроллера пока не определена).
В процессе работы будет необходимо написать приложение, которое будет забирать данные из игры, переводить в удобный формат и передавать на контроллер, а также разработать конструкцию устройства (высоту подвижного штока, размеры шестеренок, способ крепления двигателя и прочие детали).
